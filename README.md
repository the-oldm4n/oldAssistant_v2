
# Простейший скрипт для обработки голосовых команд - Voxodium

Голосовой помощник протестирован только на Windows 10 x64. Корректная работа на других ОС не гарантируется.
Есть готовый пак команд для работы с ярлыками и папками, например открытие или закрытие. Можно скорректировать слова для каждого действия.
Так же поддерживается создание собственных команд с выбором ярлыков/папок для взаимодействия.

Свежий релиз всегда можно найти [на сайте](https://owl-app.ru)

## Основные механики приложения
- Создание команды на запуск/завершение ярлыка/папки;
- Составление сценария из готовых команд для автоматического поочередного запуска шагов (скрипты);
- Вызов PrintScreen;
- Управление состоянием Bluetooth;
- Отдельный мини-виджет с кастомными кнопками, полем для заметок и мониторингом ПК через OpenHardwareMonitor;
- Выключение/перезагрузка ПК по команде;
- Команды можно подключать на кастмные кнопки виджета и вызывать их по нажатию;

## Примечания
- Приложение не имеет сертификата подлинности.
- Приложением можно пользоваться локально, распознавание vosk-модели работает без подключения к интернету, никакие данные с микрофона никуда не передаются,
но они есть в логах. Логи так же никуда не уходят, все хранится локально.
- Доступ в интернет требуется только для проверки и скачивания обновлений, а так же для авторизации клиента.
- Авторизация не обязательна, в будущем планируется сохранение команд на сервере для импорта (функция будет выборочная).

## Сборка проекта
Версия Python - 3.11

### 1. Клонирование репозитория
```bash
git clone https://github.com/the-oldm4n/voxodium
cd voxodium
```
### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
Примечание: используется самописная библиотека mygui, ее лучше отдельно прописать при установке или поправить путь в requirements.txt

### 3. Запуск
```bash
python main.py
```
